# Application screenshots

These PNG screenshots were captured with Chromium from the running app on
2026-11-10, using a separate local demo database with synthetic content.
They show the current Sites drawer, landing page, custom page browser,
custom page, visual page builder, forums, and storefront.

The demo uses configured branding and page blocks. It does not change the
application's default migrations or any existing tenant's data. Screenshots
contain no real accounts, customer content, or credentials.

Images are referenced with relative paths from the root [README](../README.md).
